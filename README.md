# Dino Island 🦖🌋

Мобильная браузерная игра. Не нужно ничего устанавливать — она открывается в браузере телефона.

**Цель:** помоги динозаврику собрать как можно больше яиц на острове, пока вулкан бросается лавой.

## Как играть
- Веди пальцем по экрану — дино бежит в ту сторону (на компьютере: стрелки или WASD).
- 🥚 яйцо = +1, золотое яйцо = +3 (исчезает через несколько секунд).
- 🔥 красный круг — туда упадёт лава. Убегай!
- 🍓 ягода восстанавливает сердечко.
- Каждые 8 очков — новый уровень, лава падает чаще.

## Как выложить игру в интернет (бесплатно, без программ)
1. На GitHub открой репозиторий → **Settings** → **Pages**.
2. В разделе *Build and deployment* выбери **Deploy from a branch**, ветку `main` (или нужную), папку `/ (root)` → **Save**.
3. Через 1–2 минуты игра будет по адресу `https://<твой-логин>.github.io/Dino-Island/`.
4. Открой ссылку на телефоне → меню браузера → **«Добавить на главный экран»** — появится иконка, как у приложения.

## Как менять игру
Вся игра — один файл `index.html`. Его можно редактировать прямо на сайте GitHub (кнопка ✏️)
или попросить AI (например, Claude) внести изменения: «добавь врагов-птеродактилей», «сделай 5 жизней» и т.п.
