# Stuck in the Stone Age

Пиксельная idle-игра для Steam (рабочее название). EN + RU.

**Сюжет.** Голуэй, 2026 год. Первый запуск самодельной машины времени закидывает героя в 10 000 год до н. э.
Машина разбита. Герой вместе с племенем вождя Оги строит поселение, «изобретает» огонь, колесо, металлы и
электричество, чтобы починить машину и вернуться домой. После запуска начинается временная петля (новая игра+):
прогресс сбрасывается, но остаётся «Эхо времени» (+10% ко всему за каждое).

## Как устроена игра
- **Карта на весь экран**, слева иконки: 🔨 стройка, 🌳 дерево улучшений, 🔬 дерево исследований,
  📘 инструкция, 🗺️ карта острова, 📖 дневник, ⚙️ настройки. Сверху ресурсы и текущая цель.
- **Остров из 12 областей**: Луг крушения, Папоротниковый лес, Речная долина, Каменные холмы,
  Черепаший пляж, Мангровое болото, Медные пещеры, Тундра мамонтов, Ржавый каньон, Долина гейзеров,
  Затерянное плато, Кратер вулкана. Закрытые области серые и под облаками.
- **Цепочка на каждую область**: расшифровать страницу инструкции (🔬) → по её загадке найти подсказку
  в уже открытой области → область открывается сразу → в ней лежит потерянная деталь машины →
  установить деталь (🔬) → можно расшифровать следующую страницу. 11 деталей, затем запуск.
- **8 пасхалок** с постоянными бонусами (телефон из 2026, резиновая уточка, монета 2031 года…).
- **Здания**: каждое ставится на карту отдельно и прокачивается уровнями. Предел уровня поднимают узлы
  дерева улучшений (5 → 10 → 15 → 25 → 40 → 60). Часть зданий работает только в своих областях
  (рудники, водяные колёса, гейзерные станции, раскопки хрония), часть — вдвое быстрее в «своей» области.
- **Дерево улучшений** (ресурсы): 25 узлов — новые здания, множители, клики, разведка.
- **Дерево исследований** (идеи): 11 страниц инструкции, 11 ремонтов, 5 научных узлов, запуск.
- Бот проходит первую петлю примерно за 11,5 часа; живой игрок — 20+ часов.

## Графика
- Пиксельное 3D: сцена рисуется в низком разрешении и растягивается чёткими пикселями, с контурами и подсветкой граней.
- Размер пикселя зависит от приближения: издалека крупный, вблизи мелкий — детали не размываются.
- Тени от солнца следуют за камерой, смена дня и ночи, костры и кристаллы светятся ночью.
- Все модели здания сливаются в один объект, а природа рисуется пачками — сотни зданий и тысячи деревьев не тормозят.
- Подсказка при наведении: что это и что даёт.

## Управление
- Мышь: тянуть — двигать камеру, правая кнопка или `Q`/`E` — вращать, колесо — масштаб, `WASD` — перемещение.
- Клик по лесу, камням, кустам — добыча; клик по машине — идеи; клик по зданию — улучшить, переместить, снести.
- Стройка: выбрать здание в 🔨, кликнуть место, `R` — повернуть, `Shift` — строить ещё одно такое же, `Esc` — отмена.
- `F11` — полноэкранный режим в версии для ПК.

## Сборка без программ на компьютере
Каждый push в папку `stone-age/` запускает GitHub Actions (`.github/workflows/stone-age-build.yml`):
1. проверка баланса ботом (если бот не дошёл до финала, сборка падает);
2. сборка для Windows (`.zip`), Linux (`.tar.gz`) и macOS (`.zip`).

Готовые файлы: GitHub → вкладка **Actions** → последний запуск «Stone Age desktop builds» → раздел **Artifacts**.
Для Windows: скачать `stuck-in-the-stone-age-Windows`, распаковать, запустить `Stuck in the Stone Age.exe`.
