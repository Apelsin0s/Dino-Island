# Stuck in the Stone Age

Пиксельная idle-игра для Steam (рабочее название). EN + RU.

**Сюжет.** Голуэй, 2026 год. Первый запуск самодельной машины времени закидывает героя в 10 000 год до н. э.
Машина разбита. Герой вместе с племенем вождя Оги строит поселение, «изобретает» огонь, колесо, металлы и
электричество, чтобы починить машину и вернуться домой. После запуска начинается временная петля (новая игра+):
прогресс сбрасывается, но остаётся «Эхо времени» (+10% ко всему за каждое).

## Как устроена игра
| Что | Где в коде |
|---|---|
| Ресурсы, здания, исследования, детали машины, сюжет, достижения | `src/data.js` |
| Экономика без интерфейса: цены, доход, клики, офлайн-прогресс, петли | `src/engine.js` |
| 3D-мир в стиле «пиксельное 3D»: модели, свет, тени, контуры, камера, расстановка зданий | `src/scene3d.js` |
| Three.js, собранный в один файл (`npm run vendor`) | `src/vendor/three.min.js` |
| Пиксельные иконки ресурсов | `src/art.js` |
| Интерфейс, сохранения, диалоги | `src/game.js`, `src/style.css`, `src/index.html` |
| Тексты интерфейса EN/RU | `src/i18n.js` |
| Обёртка для ПК (Steam) | `electron/main.js` |
| Бот-прохождение для проверки баланса | `tools/simulate.js` |

- 9 ресурсов, 14 зданий, 20 исследований, 7 этапов ремонта машины, 11 сюжетных записей, 10 достижений.
- Бот, который кликает раз в секунду и покупает с умом, проходит первую петлю примерно за 3 ч 15 мин.
  Живой игрок с перерывами потратит 5–10 часов.
- Офлайн-доход до 12 часов, автосохранение каждые 10 секунд, экспорт/импорт сохранения кодом.
- F11 — полноэкранный режим в версии для ПК.

## Графика и управление
- Мир в 3D с видом сверху под углом. Сцена рендерится в низком разрешении и растягивается чёткими пикселями,
  поверх рисуются контуры по глубине и подсветка граней. Тени от солнца, смена дня и ночи (4 минуты),
  ночью светятся костры, кратер и ядро машины.
- Здания ставит игрок: после первой покупки появляется полупрозрачная модель, клик ставит, `R` поворачивает,
  правая кнопка или `Esc` ставит автоматически. Любое здание можно выбрать кликом и переместить или повернуть.
- На карте одна модель на каждый тип здания, она растёт на 10, 25, 50 и 100 штуках.
- Камера: тянуть мышкой, правая кнопка или `Q`/`E` — вращение, колесо — масштаб, `WASD` — перемещение.
- Настройка графики (низкая/средняя/высокая) во вкладке «Ещё». Если видеокарта не поддерживает WebGL,
  игра переходит на программный рендер, а если и он недоступен, показывает понятное сообщение.

## Сборка без программ на компьютере
Каждый push в папку `stone-age/` запускает GitHub Actions (`.github/workflows/stone-age-build.yml`):
1. проверка баланса ботом (если бот не дошёл до финала, сборка падает);
2. сборка для Windows (`.zip`), Linux (`.tar.gz`) и macOS (`.zip`).

Готовые файлы: GitHub → вкладка **Actions** → последний запуск «Stone Age desktop builds» → раздел **Artifacts**.
Для Windows: скачать `stuck-in-the-stone-age-Windows`, распаковать, запустить `Stuck in the Stone Age.exe`.
