# Endless Digging: Steam, сервер и поддержка

Это памятка для владельца игры. Технические подробности — в `MULTIPLAYER.md`.

## Что нужно сделать вам (без этого игра в Steam не выйдет)

1. **Аккаунт Steamworks**: partner.steamgames.com → регистрация разработчика. Нужны паспортные данные, налоговая анкета
   (для Украины — форма W-8BEN) и банковский счёт для выплат.
2. **Steam Direct**: $100 за игру. Деньги вернутся, когда игра заработает $1000.
3. В Steamworks появятся номер приложения (App ID) и номер депо (Depot ID). Пришлите их мне. Я впишу их в
   `electron/config.json` и `steam/`.
4. **Ключ Web API издателя**: Steamworks → Users & Permissions → Manage Groups → Web API Key.
   Ключ секретный: в чат его не присылайте, он вносится только на сервер в файл `.env`.
5. **Сервер**: виртуальная машина (VPS) с 4 ядрами и 8 ГБ памяти для начала (Hetzner, OVH, DigitalOcean — около $20–40 в месяц)
   и домен (около $10 в год), например `play.endlessdigging.com`. Сервер ставится одной командой (`docker compose up -d`).
6. Ваш **SteamID64** (на сайте steamid.io по ссылке на ваш профиль): по нему сервер узнаёт владельца, у которого
   есть команды бана.
7. Страница магазина: описание, 5+ скриншотов, трейлер, капсулы. Тексты и скриншоты я подготовлю.
   Возрастной рейтинг — анкета в Steamworks (в игре есть чат, поэтому отметить «общение между игроками, модерируется»).

## Как я проверяю игру перед выпуском

- После каждого изменения на GitHub автоматически проверяется, что все скрипты запускаются, и идут тесты сервера.
  Два бота заходят, копают, пытаются жульничать (слишком большой инструмент, слишком далеко, слишком быстро),
  пишут в чат с матом и ссылками. Потом бана проверяется после переподключения, деньги — после перезапуска сервера.
- Сам я запускаю игру в двух окнах браузера сразу (как двое игроков) и смотрю картинку: видят ли они друг друга,
  появляются ли ямы, работает ли чат. Так проверена нынешняя версия.
- Десктопную (Steam) версию я запускаю здесь в Electron на виртуальном экране: проверяю, что она грузится
  и показывает меню. Вход через Steam здесь проверить нельзя: нет клиента Steam. Это проверяете вы на своём ПК
  с бета-ветки.

## Как выходят обновления

- **Игра (клиент)**: Steam сам скачивает обновление игрокам. Порядок такой: я делаю сборку, она уходит на ветку
  `beta` в Steam, вы и тестеры пробуете, потом вы нажимаете «Set live» в Steamworks (или запускаете сборку
  с веткой `default`). Если старая игра не подходит к новому серверу, сервер вежливо просит обновиться.
- **Сервер**: обновляется без нового выпуска игры: `git pull && docker compose up -d --build`. Игроки на
  ~5 секунд видят «Связь потеряна, переподключаемся…», потом игра сама подключается обратно. Ямы и деньги
  хранятся на диске и не теряются.

## Как я исправляю ошибки «в реальном времени»

- Игра сама отправляет на сервер свои ошибки: текст и место в коде, без личных данных. Жалобы игроков
  и чат тоже пишутся в журнал.
- Чтобы я видел эти журналы, нужен доступ. Самый простой вариант — завести на сервере секретный `ADMIN_API_TOKEN`
  и добавить его в настройки этой среды Claude (я попрошу через защищённую форму, в чат его не пишите).
  Тогда я могу забирать `/api/admin/errors` и `/api/admin/reports`.
- Я не работаю круглосуточно сам по себе. Я работаю, когда открыта сессия, или по расписанию: можно поставить
  задачу, например каждое утро, «посмотри ошибки и жалобы, исправь, проверь, сделай ветку». Исправление проходит
  те же тесты. На сервер его выкатываете вы одной командой, или я, если вы дадите доступ к серверу.
- Срочные меры доступны вам прямо в игре: `/ban`, `/mute`, `/kick`, `/say`.
- Резервные копии: папку `server/data` раз в сутки копировать в другое место (у хостинга это обычно одна галочка
  «Backups»).

## Что уже сделано для кооператива

- Одна общая Земля для всех. У каждого свой участок: новые игроки получают места по спирали вокруг Кривого Рога,
  в 150 м друг от друга.
- Видно других игроков: человечек в каске своего цвета с именем над головой. Видно, как они копают.
- Сервер сам считает каждый удар и деньги, поэтому деньги в браузере не подделать. Исследования тоже покупаются
  через сервер.
- Чат по Enter; его слышат игроки поблизости. Фильтр скрывает мат на многих языках, ссылки, телефоны,
  почту и ники в соцсетях. Есть защита от флуда, автоматическое отключение чата за мат, жалобы.
- Вход только через Steam (в разработке — гостевой вход для тестов).
- Владелец банит навсегда, отключает чат, выгоняет, делает объявления.
