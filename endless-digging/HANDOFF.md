# Endless Digging — передача в новый чат

Прочитай этот файл и `README.md`, остальное смотри по мере надобности. Отвечай по-русски, коротко.

## Что это
Игра от первого лица: копатель с ложкой должен выкопать всю Землю (масштаб 1:1, радиус 6 371 км).
Жанр как Moon Sweepers: начинаешь с ложки, продаёшь землю, покупаешь улучшения, потом автоматизация.
Цель — Steam (Electron), проверка на телефоне по ссылке. Языки RU + EN.

## Где что лежит
- `src/` — играбельная тестовая сцена, уже в стиле варианта 5: `world.js` (планета, копание), `scene.js` (графика), `game.js` (игрок, управление ПК и телефон, интерфейс),
  `sdf.js` (гладкая лепка моделей), `assets.js` (рука с ложкой, ведро, деревья, пункт приёма, фургон) — общие с look-dev.
- `lookdev/look.js` — сцена для рендера кадров стиля (варианты 1–5).
- `lookdev/renders/v5-wide.jpg`, `v5-close.jpg` — утверждённый вид.
- `tools/lookdev-render.js` — рендер без окна: `node tools/lookdev-render.js <папка> "v=5&q=draft&shots=wide"`. Черновик `q=draft` ~20 с, `q=final` ~75 с.
- `npm install && npm run vendor` — собрать Three.js (в репозитории уже лежит собранный).

## Решения владельца (не переспрашивать)
1. Название: **Endless Digging**.
2. Графика: вариант 5 в `look.js` — как в Moon Sweepers (чистая гладкая земля, редкие гранёные камешки и пучки травы, резкие длинные тени с тенью копателя, бело-оранжевая техника), цвета насыщенные.
3. Рука голая, без перчатки; ложка зажата в кулаке так, что ручку видно.
4. Старт: только ложка и ведро, лопаты нет. Копаешь, несёшь землю в пункт приёма, покупаешь улучшения.
5. Земля настоящая: реальные берега, рельеф, биомы. Сначала открыта Европа. Месторождения на реальных местах, статус сверять на 2026 год.
6. Старт — Украина (владелец: «в Украине много полезных ископаемых»). Предложен Кривой Рог (железо; рядом Никополь — марганец, Донбасс — уголь); точную точку владелец не подтвердил.

2. Ложка, ведро, пункт приёма, деньги, первые улучшения. Сетку грунта у игрока сделать мельче: сейчас 40 см, нужно 2–4 см (из‑за 40 см край ямы ступенчатый, а радиус копка ложкой временно 24 см).
3. Настоящая Европа: берега (Natural Earth, raw.githubusercontent.com), рельеф (s3.amazonaws.com/elevation-tiles-prod), биомы, карта мира с закрытыми континентами.
4. Месторождения: база USGS (`https://mrdata.usgs.gov/mrds/mrds-csv.zip`, 304 632 записи, Европа ~2 600; нет угля и соли, статусы устарели, есть дубли) + другие наборы с mrdata.usgs.gov + ручная сверка главных рудников.
